# DSH 待办插件 v2 · 设计文档

**日期**: 2026-10-22
**状态**: 待评审
**基于**: v1（[2026-10-22-dsh-todolist-design.md](./2026-10-22-dsh-todolist-design.md)），v2 只做增量
**核心决策**: 循环任务用「模板 + 完成记录」，日历以「月视图」为主

---

## 一、要解决的问题

v1 有两个明确缺口，用户实际使用后提出：

1. **新增时无法指定日期**。`+ 新建` 走的是「一句话快速添加」，日期只能从文本里解析；不写日期就落进「未排期」。需要一个能手动填全部字段的编辑弹窗。
2. **没有循环任务**。「每个工作日交日报」「每周五检查代码」这类事只能每天手动新建。
3. **没有日历视角**。用户想看「这个月哪天有什么」，参考企业微信的日程月视图。

## 二、非目标

| 不做 | 原因 |
|---|---|
| 单次例外（只改某一次的标题/时间） | 模板模型下这是另一套机制（exception 表），v2 不做；改规则影响所有未来实例，符合预期 |
| 复杂重复规则（每月第 N 个星期几、隔周） | 先覆盖 每天 / 每周X / 每月N号 三档，够用再说 |
| 日历里拖拽改期 | 拖拽是独立交互，等日历用起来再评估 |
| 循环任务的「历史完成」视图 | 只记录、不展示；完成记录用于「今天做没做」的判断 |

## 三、数据模型

在 v1 记录上新增两个字段：

```jsonc
{
  "id": "t_...",
  "title": "交日报",
  "dueDate": "2026-10-22",          // 循环任务：第一次发生的日期（起始日）
  "dueTime": "18:00",

  "repeat": {                        // null 表示不循环
    "freq": "daily" | "weekly" | "monthly",
    "interval": 1,                   // 每 N 天/周/月，v2 只允许 1
    "weekdays": [1, 2, 3, 4, 5],     // 仅 weekly：ISO 周几，1=周一
    "monthDay": 5,                    // 仅 monthly
    "until": "2026-12-31"            // 可选，含当天；null 表示无限
  },

  "completions": {                   // 仅循环任务用；键为本地日期 YYYY-MM-DD
    "2026-10-22": "2026-10-22T09:12:00.000Z"
  },

  "done": false,                     // 循环任务恒为 false（完成记在 completions 里）
  "doneAt": null,
  "doneBy": null,
  "verifiedAt": null
}
```

**为什么不用 `done` 表示循环任务的完成**：一条循环任务会完成很多次，`done` 是单值布尔，表达不了。用 `completions` 按日期记录，天然支持「今天做完了、昨天没做」。

### 3.1 实例展开（纯函数）

```js
// lib/repeat.js
occurrencesBetween(todo, fromKey, toKey) -> string[]   // 该区间内所有应发生的日期
nextOccurrence(todo, fromKey) -> string | null         // 下一个应发生的日期（用于列表行显示）
isDueOn(todo, dateKey) -> boolean
```

展开规则：
- `freq: daily`：从起始日每天一次；
- `freq: weekly` + `weekdays`：每周的这些星期几；
- `freq: monthly` + `monthDay`：每月 N 号（该月没有 N 号则跳过）；
- 一律跳过起始日之前的日期；`until` 之后不再发生。

**这些是纯函数，必须单测**（跨月、跨年、闰年 2 月、`until` 边界、`weekdays` 为空时回退到起始日的星期）。

### 3.2 列表视图里循环任务怎么显示

- `dueDate` 显示为 `nextOccurrence(todo, 今天)`——即"下一次该做的时间"，它会随着完成自动往后滚。
- 行上带一个「循环」徽标（`repeat` 非空时）。
- 勾选 = 完成**这一次**：写 `completions[该次日期]`，然后行自动滚到下一次。
- 循环任务**不进「已完成」分组**（避免每次完成都堆积一条）；详情里显示「上次完成：MM-DD」。

### 3.3 日历视图

- 月网格，7 列（周一起始）。
- 每天格子：最多显示 2 条，超出显示 `+N`；每条一行小字（标题，可带优先级色点）。
- 今天高亮；非本月的日期淡显。
- 点某天 → 右侧详情列切换成「当天清单」，可勾选、可新建（新建时日期预填为该天）。

## 四、接口变更

```ts
// 新增
todo.occurrences({ from, to })   // 区间内所有发生的实例（含循环展开），供日历用
                                 // → [{ todoId, date, title, priority, category, done }]

// 修改
todo.complete(id, done?, by?, date?)   // date 缺省为今天；循环任务写/删 completions[date]
todo.create(input)                     // input 增加 repeat?: { freq, interval?, weekdays?, monthDay?, until? }
todo.update(id, patch)                 // patch 可改 repeat
```

工具 `personal_todo`：
- `complete` 增加可选 `date`（默认今天）；
- `list` 的循环任务在文本里标注 `（循环·下次 10-24）`；
- 新增 `occurrences` 不需要暴露给模型（模型问"这周有什么"用 `list` 足够）。

## 五、界面

### 5.1 新建/编辑弹窗

`+ 新建` 打开弹窗（不是跳页）。字段：

| 字段 | 控件 | 默认 |
|---|---|---|
| 标题 | 单行输入 | 空（必填） |
| 备注 | 多行文本 | 空 |
| 日期 | 快捷按钮（今天/明天/下周一）+ 原生 `date` 输入 | 今天 |
| 时间 | 原生 `time` 输入 | 空 |
| 优先级 | 三选一（高/中/低） | 无 |
| 分类 | 单行输入 + 已有分类的候选 | 空 |
| 重复 | 下拉：不循环 / 每天 / 每周 / 每月 | 不循环 |
| 每周时 | 一~日 七个可点按钮 | 与所选日期一致 |
| 每月时 | 1–31 数字 | 与所选日期一致 |
| 结束 | 可选日期 | 空（无限） |

- 弹窗用宿主 token，`role="dialog"`、Esc 关闭、点遮罩关闭、首字段自动聚焦。
- 「保存」后才落库；关闭不保存。
- 快速添加输入框保留，与弹窗并存。

### 5.2 页头视图切换

页头加一个分段控件：`列表 | 日历`。选择记在组件状态里（不跨刷新持久化，v2 不做）。

### 5.3 日历

见 §3.3。月切换用 `‹ 2026年10月 ›`，点今天按钮回到当月。

## 六、错误处理

| 场景 | 表现 |
|---|---|
| 重复规则非法（weekdays 空、monthDay 越界） | 弹窗内联报错，不关闭 |
| 循环任务被删除 | 连同 `completions` 一起删，无残留 |
| 老记录没有 `repeat` / `completions` | 按 null / 空对象处理，不崩 |
| 日历区间过大（例如一次查一年） | 上限 400 天，超出截断并在日志告警 |

---

## 七、验收标准

1. 点「+ 新建」弹窗，选 2026-11-05 + 时间 + 优先级 + 分类，保存后出现在「本周」或对应分组，日期正确。
2. 建一条「每个工作日 18:00 交日报」，起始日今天：日历上本周一到周五都出现；勾掉今天，只有今天消失，明天仍在。
3. 勾掉循环任务的今天后，列表行自动滚到下一天，且不进「已完成」。
4. 「每月 31 号」的任务，在 2 月不出现，3 月 31 日出现。
5. 日历翻到 2027 年 2 月，循环任务按规则出现，不越界、不重复。
6. 老数据（v1 写的、没有新字段）加载后一切正常。
7. 卸载/重装后 `completions` 仍在。

## 八、风险

| 风险 | 缓解 |
|---|---|
| 展开逻辑写错导致日历漏任务或重复 | 纯函数 + 单测（跨月/跨年/闰年/until） |
| 循环任务让「积压」判定失真 | 积压只对非循环任务生效（循环任务永远"下一次"，不会积压） |
| 弹窗与快速添加语义不一致 | 两者都走 `create`，字段同名同义 |
| 日历一次查询过大 | 固定查当月 + 前后各一个月 |
