评审注记（非界面）
开关行与初始态（第十节 / Q6）：循环 / 结束日期字段区下方独立开关行；新建默认关，编辑 = initial.automation?.enabled === true；态①为用户手动开启后的表单。开启时展开 time（HH:mm）输入。
提醒时间预填（第四节）：新建 = dueTime，为空则 09:00；编辑 = automation.time ?? dueTime ?? 09:00。示例 dueTime=17:30 → 预填 17:30。
Q1 · until→partial：until 仅作用于待办侧，不映射宿主 rrule；创建期界面不做任何提示，同步后编辑回显 partial 徽标（语义解释进徽标 tooltip）。
Q2 / Q3 · 固定策略：时区取宿主进程 IANA 时区落库（示例 Asia/Shanghai），后续同步沿用；执行位置固定 new_once。两者创建期均不在界面呈现（不在白名单、仅约定于 tooltip）。
态② 降级（第六节）：CLI profile / 未挂载 Schedule → capabilities.automation=false，开关禁用 + 短标签「暂不可用」，完整原因收 tooltip；待办功能零影响；若强制带意图保存 → HTTP 400 automation-unavailable，待办本体照常保存（不落 automation 字段）。
态③ 单行状态：徽标 + HH:mm + 相对上次同步时间；taskId 尾 8 位 / lastSyncedAt 绝对时间 / lastError 全文 / orphan 详情全部收 tooltip，界面零常驻细节。
关闭开关 = 删除编排（第七节 / Q5）：保存 automation={enabled:false} → 宿主 edit delete；成功或 schedule_not_found 视为成功并清除本地记录；其他失败 → status=error + lastError，下次保存重试（记录还在）。
保存响应一次性提示（第十节，非常驻 toast，不在界面常驻文案白名单内）：automation-unavailable →「待办已保存，但当前 DSH 不支持自动化任务」；status=error →「待办已保存，自动化任务同步失败：<lastError>；下次编辑保存将自动重试」；notice →「自动化任务已不存在，已解除关联」。
